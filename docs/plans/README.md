# Plan artefacts

Plans written before implementation, committed as durable state.

The protocol is in [`AGENTS.md`](../../AGENTS.md#plan-first) and the file format is in
[`.github/instructions/docs-and-plans.instructions.md`](../../.github/instructions/docs-and-plans.instructions.md).

Short version: write the plan, stop, get agreement, then implement. If implementation shows
the plan was wrong, update the plan — do not diverge silently. Abandoned plans stay, with the
reason.
